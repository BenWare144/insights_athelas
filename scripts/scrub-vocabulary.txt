# UI vocabulary for scripts/scrub-capture.js.
#
# One label per line. A piece of page text survives the scrub only if it matches
# a line here exactly (case-insensitive; a trailing ":" or "*" is ignored).
# Everything else becomes "Xxxx xx 000" placeholders.
#
# RULES FOR ADDING A LINE
#   - App chrome only: a button, tab, column header, field label, menu item.
#   - NEVER a person's name, a clinic name, a diagnosis, an exercise, or anything
#     that differs from patient to patient.
#   - Be wary of single words that are also names (May, April, June, Rose, Grant):
#     a first name shown in its own element would then be kept. Prefer the full
#     label ("Clear All Filters") over the bare word.
#   - "^Phrase" keeps Phrase at the START of a longer label and scrubs the rest
#     (unless the rest is itself a label):  ^Scores for  ->  "Scores for Xxxx".
#   - "$Phrase" does the same at the END:   $interventions -> "00000 - Xxxx interventions".
#   - "Label: value" needs no rule: when the part before the colon is a label
#     here, the label is kept and the value is scrubbed.
#
# Survey names are added automatically from surveys/survey-scoring.js.
# The scrubber's own list of what it removed is _scrub-review.txt in the RAW
# folder; it contains raw page text, so read it there, not here.
